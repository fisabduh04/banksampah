# Waste Bank Project Context

## Purpose

This application is a scalable Waste Bank Management System.

Core business areas may include:

- users;
- customers / nasabah;
- officers / petugas;
- waste categories;
- waste types;
- waste prices;
- deposits;
- withdrawals;
- customer balances;
- balance mutations;
- inventory;
- waste sales;
- cash transactions;
- accounting;
- reporting;
- audit trails;
- transaction evidence / attachments.

## Development Principle

The application must remain understandable for a developer who is still learning Laravel while preserving a path toward professional production use.

Preferred philosophy:

```text
Beginner-friendly
+
Laravel-native
+
Database-safe
+
Refactorable
+
Production-oriented
```

Avoid both extremes:

```text
Overengineered from day one
```

and:

```text
Quick CRUD that must later be discarded
```

## Current Learning Sequence

Unless the existing project is already further ahead, prioritize:

```text
1. Understand existing project
2. Customer / Nasabah CRUD
3. Waste Category CRUD
4. Waste Type CRUD
5. Waste Price CRUD
6. Eloquent relationships
7. Authentication
8. Roles and permissions
9. Deposit master-detail transaction
10. Balance ledger
11. Inventory ledger
12. Withdrawals
13. Waste sales
14. Reporting
15. Accounting
16. Audit trail
17. Testing
18. Production hardening
```
